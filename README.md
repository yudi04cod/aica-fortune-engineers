# Fortune Cookie Funnies for Engineers

One original fortune cookie message for a software engineer, written by a
small deterministic program (`main.ts`) for the make.fun bounty
**Fortune Cookie Funnies for Engineers**.

## The fortune

> You will meet the code you wrote at 2 a.m. and swore was temporary. It is now load-bearing.

## How it works

Run `node main.ts`. It writes that single line (91 characters, one line,
no trailing newline) to `/output/entry.txt`. No input, no randomness, no
network — the same fortune on every run.
